楽天市場では、毎月5日・10日・15日・20日・25日・30日が「5と0のつく日」です。その日にエントリーして、楽天市場の買い物を楽天カードで払うと、ポイントが+1倍になります。楽天カードの案内にある「ポイント4倍」は、この+1倍にふだんの3倍を足した数字です。

この記事では条件と上限を楽天カードの公式ページ（2026年11月26日に確認）をもとにまとめ、お買い物マラソンの買いまわりとどう重なるかを並べます。

## 結論

- **エントリーは開催日ごとに毎回必要です。** その日のうちにエントリーすれば、エントリーより前のその日の買い物も対象です。
- **5と0のつく日に増えるのは+1倍だけです。** 「ポイント4倍」のうち3倍は、楽天カードで払えばいつでも付きます。
- **上限は月1,000ポイントです。** 税抜で月100,000円の買い物で届きます。
- **お買い物マラソンの買いまわりの上限7,000ポイントとは別に付きます。** 買いまわりが上限に届いていても、5と0のつく日の+1倍は止まりません。

## 「ポイント4倍」の内訳

5と0のつく日に楽天市場で楽天カードを使ったときの倍率は、次の4つを足したものです。5と0のつく日だけに付くのは、「5と0のつく日特典」の+1倍です。

| 内訳                      | 倍率 | 上限            |
| ------------------------- | ---: | --------------- |
| 楽天市場の通常ポイント    |  1倍 | なし            |
| 楽天カードの通常分（SPU） | +1倍 | なし            |
| 楽天カードの特典分（SPU） | +1倍 | 月1,000ポイント |
| 5と0のつく日特典          | +1倍 | 月1,000ポイント |
| 合計                      |  4倍 |                 |

楽天カードの特典分の上限は、楽天プレミアムカード（楽天ブラックカード、楽天ビジネスカードを含む）なら月5,000ポイントです。いちばん上の1倍は楽天市場が、残りの3倍は楽天カードが付けます。

公式ページの例では、税抜10,000円の商品を楽天カードで払うと410ポイントです。楽天カードの通常分は消費税・送料を含む金額にかかるので110ポイント、ほかの3つは税抜の金額にかかるので100ポイントずつです。

## 確かめた時点の条件

:::info
2026年11月26日に、楽天カードの[5と0のつく日のページ](https://event.rakuten.co.jp/campaign/card/pointday/)で確かめた内容です。条件は予告なく変わることがあります。買う前に公式ページで確かめてください。
:::

- 開催日\
  毎月5日・10日・15日・20日・25日・30日の0:00〜23:59です。2月は30日がないので5回です。
- エントリー\
  必要です。開催日ごとに毎回エントリーし、開催日以外にはエントリーできません。その日のうちにエントリーすれば、エントリーより前の買い物も対象です。
- 対象の支払い\
  楽天市場での買い物を楽天カードで払った分です。デザインカードなども含みますが、楽天ビジネスカードプラチナと楽天コーポレートカードは対象外です。家族カードで払った分も、買い物をした楽天IDに付きます。
- 対象のサービス\
  通常購入、定期購入、頒布会、楽天ブックス、楽天Kobo、楽天ふるさと納税です。楽天ふるさと納税は+1倍の対象ですが、楽天市場のお買い物通常ポイント（1倍）は付きません。
- 定期購入・頒布会\
  お届けの回ごとに、注文が確定した日が5と0のつく日で、その日にエントリーしていると対象です。23時45分より後に申し込むと、注文の確定が翌日になり対象外になることがあります。
- ポイントが付く金額\
  楽天カードで払った楽天市場の金額から、消費税・送料・ラッピング料を除いた金額です。1商品あたり税抜100円未満の商品は、いくつ買っても対象になりません。
- 上限\
  月1,000ポイント（期間限定ポイント）です。SPUの楽天カードの上限とは別に数えます。
- 付与\
  期間限定ポイントで、買い物をした月の翌月15日ごろに付きます。買い物の情報が楽天カードに届くのが翌月になったときは、翌々月15日ごろです。期限は付いた翌月の末日です。+1倍の分は、付くまで「獲得予定ポイント」に出ません。

上限の1,000ポイントは、+1倍のかかる税抜の金額が月100,000円で届きます。5と0のつく日は月に6回ありますが、上限はその合計にかかります。

## 買いまわりの上限7,000ポイントとは別

お買い物マラソンの買いまわりの上限は、公式の案内では基本が7,000ポイントで、買いまわりの特典のポイントだけにかかります。楽天市場の[お買い物マラソンのガイド](https://event.rakuten.co.jp/campaign/point-up/marathon/guide/)には、次のように書かれています。

> ショップ買いまわりの上限7,000ポイント(期間限定ポイント)とは別に、各キャンペーンごとの上限ポイント数が獲得可能です。

5と0のつく日のページのよくある質問でも、「ショップ買いまわり」とは原則として別のキャンペーンとして数え、それぞれにポイントが付くとしています。

たとえば、お買い物マラソンの期間の5と0のつく日に、10店舗で税抜77,778円を楽天カードで買ったとします。買いまわりはこの金額で上限の7,000ポイントに届きますが、5と0のつく日の+1倍は上限の外で、最大777ポイントが別に付きます。逆に、5と0のつく日の上限1,000ポイントに届いても、買いまわりの倍率は下がりません。

## ほかのキャンペーンとの重なり方

5と0のつく日のページのよくある質問では、ほかのキャンペーンとは原則として別に数え、それぞれにポイントが付くとしています。ただし「一部重複した適用がされないキャンペーンもございます」とも書かれているので、重ねたいキャンペーンのページも確かめてください。

- SPU\
  「ポイント4倍」のうち、楽天カードの+2倍はSPUの分です。SPUの楽天カードの上限と、5と0のつく日の上限1,000ポイントは別に数えます。
- お買い物マラソン\
  買いまわりの特典は、上の節のとおり上限も別です。期間に5と0のつく日が入っていれば、その日に買った分に+1倍が足されます。
- 楽天カードの分割払い\
  同じページに、楽天カードの分割払いで最大4倍になるキャンペーンも載っています。別のエントリーが必要で、分割払いの手数料（実質年率12.25%〜15.00%）がかかります。5と0のつく日のエントリーとはボタンが違うので注意してください。

## ポイントスプリントで計算する

[ポイントスプリント](/)のプランには、「5と0のつく日」が最初から入っています。エントリーして楽天カードで払う日があれば、プランの設定の「キャンペーン」で ON にします。

ON にすると、5日・10日・15日・20日・25日・30日の注文に、税抜の金額で+1倍を足します。上限は買いまわりとは別に月1,000ポイントで、同じ月のほかのプランとも分け合って数えます。お買い物マラソンの買いまわりの上限に届いたあとで、5と0のつく日に買う分がいくら増えるかも、プランに注文を入れれば確かめられます。

買いまわりの上限にいくらで届くかは、[お買い物マラソンはいくら・何店舗買えばいいか](/guides/how-much-to-buy)にまとめています。
