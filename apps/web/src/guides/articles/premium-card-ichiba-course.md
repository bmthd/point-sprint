楽天プレミアムカードの案内には「毎週火曜・木曜4倍」と書かれています。このうち楽天プレミアムカードだけに付く1倍が、「楽天市場コース」の特典です。毎週火曜日と木曜日に楽天市場で楽天プレミアムカードを使うと、ポイントが+1倍になります。

この記事では条件と上限を楽天カードの公式ページ（2026年11月25日に確認）をもとにまとめ、2019年からの公式ページの版で何が変わったかを並べます。

## 結論

- **毎週火曜日と木曜日に、楽天市場で楽天プレミアムカードを使うと+1倍。** 上限は月10,000ポイントです。
- **SPUの「楽天カード特典分」（月5,000ポイントまで）とは別の特典です。** 両方の上限が別に数えられます。
- **曜日は注文日で決まります。** 楽天市場の購入履歴に出る注文日（購入日時）です。
- **楽天カード以外で払った注文、予約・定期購入・頒布会、楽天ブックスは対象外です。**

## 「毎週火曜・木曜4倍」の内訳

火曜日と木曜日の楽天市場での倍率は、次の4つを足したものです。

| 内訳                    | 倍率 | ポイント     | 上限             |
| ----------------------- | ---: | ------------ | ---------------- |
| 楽天市場の通常ポイント  |  1倍 | 通常ポイント | なし             |
| 楽天カード通常分        | +1倍 | 通常ポイント | なし             |
| 楽天カード特典分（SPU） | +1倍 | 期間限定     | 月5,000ポイント  |
| 楽天市場コース          | +1倍 | 通常ポイント | 月10,000ポイント |
| 合計                    |  4倍 |              |                  |

火曜日と木曜日以外は、楽天市場コースの1倍がなくなり3倍です。SPUのほかの項目（楽天モバイルなど）や、お買い物マラソンの買いまわりは、この4倍の上に足されます。

## 確かめた時点の条件

:::info
2026年11月25日に、楽天カードの[楽天プレミアムカードのページ](https://www.rakuten-card.co.jp/card/rakuten-premium-card/)、[選べるサービスのページ](https://www.rakuten-card.co.jp/card/rakuten-premium-card/detail3/)と[特典の詳細のページ](https://www.rakuten-card.co.jp/card/rakuten-premium-card/service/choose_p/)で確かめた内容です。
:::

- 名前\
  選べるサービスのページでは「楽天市場コース」です。特典の詳細のページは2025年から「楽天市場特典」と書いています。どちらも同じ特典です。
- 対象の日\
  毎週火曜日と木曜日です。楽天市場の購入履歴に出る注文日（購入日時）をカードの利用日とします。
- 対象の支払い\
  楽天市場での買い物を楽天プレミアムカードで払った分です。翌月末までに楽天カードが利用を確認できたものが対象です。家族カードは対象外です。
- ポイントが付く金額\
  楽天市場でのカード利用額100円につき1ポイントです。公式ページの例は「11,000円（税込み）」に110ポイントで、税込の金額に付きます。
- 上限\
  月10,000ポイントです。カードの利用額でいうと、火曜日と木曜日の合計で月100万円です。
- 対象外\
  予約・定期購入・頒布会、楽天ブックス、ポイントで払った分、注文の後に支払い方法を楽天カードへ、または楽天カードから変えた分、キャンセルした分です。
- 付与\
  通常ポイントで、利用月の翌々月末ごろに付きます。楽天カード通常分や楽天カード特典分とは付く日が違います。
- 登録\
  楽天e-NAVIで特典を登録します。2025年1月15日以降に入会した人は、楽天市場コースが自動で適用されます。

## SPUの「楽天カード特典分」との違い

楽天市場の[SPU](https://event.rakuten.co.jp/campaign/point-up/everyday/point/)にも楽天プレミアムカードの項目がありますが、別の特典です。

|            | 楽天市場コース       | SPUの楽天カード特典分                   |
| ---------- | -------------------- | --------------------------------------- |
| 対象の日   | 毎週火曜日・木曜日   | 毎日                                    |
| 倍率       | +1倍                 | +1倍                                    |
| 上限       | 月10,000ポイント     | 月5,000ポイント（楽天プレミアムカード） |
| ポイント   | 通常ポイント         | 期間限定ポイント                        |
| 付く金額   | カード利用額（税込） | 消費税・送料・ラッピング料を除く金額    |
| 付けるのは | 楽天カード           | 楽天市場（SPUの特典）                   |

火曜日と木曜日に楽天プレミアムカードで払えば、両方が付きます。

## これまでの変遷

楽天カードの公式ページは同じURLで書き換わります。インターネットアーカイブに保存された[特典の詳細のページ](https://www.rakuten-card.co.jp/card/rakuten-premium-card/service/choose_p/)と[楽天プレミアムカードのページ](https://www.rakuten-card.co.jp/card/rakuten-premium-card/)の過去の版（2019年1月から2026年8月）を読み比べました。

- 2019年1月の版\
  「選べるサービス」として、楽天市場コース・トラベルコース・エンタメコースから1つを選ぶ形でした。楽天市場コースは毎週火曜日・木曜日の「プレミアムカードデー」に+1%で、上限は楽天IDごとに10,000ポイントでした。予約・定期購入・頒布会と楽天ブックスが対象外なのは今と同じです。コースは変えた月を含めて6カ月は変えられず、選ばなかった人は楽天市場コースに自動で登録されました。
- 2019年11月の版\
  倍率の書き方が「%」から「倍」になり、楽天市場コースを選ぶと「最大6倍」と案内していました。楽天市場での楽天プレミアムカードの利用に、特典ポイントが3倍付いていたためです。
- 2023年9月の版から2023年12月の版のあいだ\
  楽天プレミアムカードのSPUの上乗せ（「楽天カード特典分がさらに2倍」）がなくなりました。プレミアムカードデーの倍率の案内は「最大6倍」から「最大4倍」になりました。楽天市場コースの+1倍と月10,000ポイントの上限は変わっていません。
- 2024年7月の版\
  「2025年1月15日(水)以降、選べるサービスは『楽天市場コース』のみ」という案内が加わりました。2024年4月の版にはまだありません。それまでにトラベルコースやエンタメコースを選んでいた人は、そのまま使えます。
- 2025年4月の版\
  特典の詳細のページが「楽天グループサービスの優待特典」になり、コースの名前が「楽天市場特典」「楽天トラベル特典」「ブックス/TV特典」になりました。2025年1月15日以降に入会した人は楽天市場特典だけを登録でき、入会の翌月末までに登録しないと自動で適用されます。
- 今（2026年11月）\
  新しく作ったカードには楽天市場コースが自動で登録されます。2025年1月14日以前に入会して、ほかのコースを選んでいた人は楽天市場コースに変えられますが、変えると元のコースには戻せません。

火曜日と木曜日に+1倍、上限は月10,000ポイントという楽天市場コースの中身は、2019年1月の版から変わっていません。

## ポイントスプリントで計算する

[ポイントスプリント](/)では、プランの設定の「キャンペーン」で「＋ プレミアムカード 火・木」を押すと、楽天市場コースがプランに入ります。

楽天市場の火曜日と木曜日の注文に+1倍を足し、上限の月10,000ポイントまで数えます。注文の「楽天カードのポイント」をオフにした注文、つまり楽天カード以外で払った注文には付きません。SPUの楽天プレミアムカード（特典分）とは別に数えます。
