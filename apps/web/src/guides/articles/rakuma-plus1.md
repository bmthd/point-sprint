お買い物マラソンや楽天スーパーSALEのページには、「ショップ買いまわり＆ラクマ購入でポイント最大11倍」と書かれています。最大10倍の買いまわりに足される残りの1倍は、楽天ラクマの「買いまわりラクマ特典」です。期間中にラクマで合計1,000円以上買うと、楽天市場での買い物の倍率が+1倍になります。

この記事では条件と上限を楽天ラクマの公式ページ（2026年11月24日に確認）をもとにまとめ、2023年から開かれてきた回で何が変わったかを並べます。

## 結論

- **ラクマで期間中に合計1,000円以上買うと、楽天市場での買い物が+1倍。** 上限は1回の開催で500ポイントです。
- **お買い物マラソンにエントリーしていれば、この特典にもエントリーしたことになります。** 別にエントリーしなくても対象です。
- **+1倍が付くのは、1,000円以上買ったショップの分だけ。** 買いまわりで1店舗と数えるショップと同じです。
- **SPUの「楽天ラクマ」（+0.5倍）とは別の特典です。** SPUはラクマで売ると毎月付き、こちらはラクマで買うと大型イベントの回ごとに付きます。

## 「最大11倍」の内訳

楽天市場での買い物の倍率は次の3つを足したものです。

| 内訳                               |     倍率 |
| ---------------------------------- | -------: |
| 通常ポイント                       |      1倍 |
| ショップ買いまわり（10店舗で最大） |     +9倍 |
| ラクマ購入（買いまわりラクマ特典） |     +1倍 |
| 合計                               | 最大11倍 |

公式ページの計算例では、ラクマで1,000円以上買い、楽天市場で3ショップを回ると、楽天市場での買い物は4倍（通常1倍、買いまわり+2倍、ラクマ特典+1倍）です。

## 確かめた時点の条件

:::info
2026年11月24日に、楽天ラクマの[買いまわりラクマ特典のページ](https://rakuma.rakuten.co.jp/info/campaign/buy/kaimawari/)で確かめた内容です。このページは開催のたびに書き換わります。買う前に、その回の条件を確かめてください。
:::

- 開かれる時期\
  お買い物マラソン、楽天スーパーSALE、ブラックフライデーの期間に合わせて開かれます。ポイントアップ期間はそのイベントと同じです。
- エントリー\
  必要です。ただし、イベントのキャンペーンページでエントリーした場合も対象です。この特典へのエントリーは楽天PointClubのキャンペーンエントリー履歴にイベントへのエントリーとして表示されます。
- ラクマでの条件\
  期間中のラクマでの購入の合計が、クーポンを使った後で1,000円以上になることです。1回で1,000円でなくても、合計で届けば対象です。キャンセルした取引は含みません。チケットの優待券・割引券や使用済み切手・官製はがきなど、一部のカテゴリは合計に含みません。
- 取引の完了\
  期間中に購入手続きを終え、翌月末までに出品者と購入者の双方の評価を終える必要があります。
- 楽天市場での対象\
  「対象期間中の1ショップでのお買い物合計金額1,000円(税込)以上」のショップの買い物です。同じショップでの購入は合計します。金券類など換金性の高い商品は原則として対象外です。
- ポイントが付く金額\
  税抜、送料別、クーポンを使った後の金額です。
- 上限\
  1回の開催で500ポイントです。ショップ買いまわりの上限とは別の枠です。
- 付与\
  期間限定ポイントで、キャンペーン終了の翌々月15日ごろに付きます。お買い物マラソンの買いまわりの特典とは付く日が違います。

上限の500ポイントに届くのは、対象の買い物が税抜50,000円のときです。10%の商品なら、税込でおよそ55,000円です。

## ラクマでの買い物に付くポイント

買いまわりラクマ特典には楽天市場の+1倍のほかに、ラクマでの買い物に付くポイントが2つあります。

| 特典  | 付く買い物 | 中身                                       | 上限          |
| ----- | ---------- | ------------------------------------------ | ------------- |
| 特典1 | 楽天市場   | 倍率が+1倍                                 | 500ポイント   |
| 特典2 | ラクマ     | 100円につき1ポイント                       | なし          |
| 特典3 | ラクマ     | 楽天市場で回ったショップ数に応じて+1〜10倍 | 1,000ポイント |

特典1と特典3はラクマでの合計が1,000円以上のときだけ付きます。特典2は1,000円に届かなくても付きます。特典1と特典3を合わせた上限は1,500ポイントで、ブラックフライデーのページの「7,000ポイント（ショップ買いまわり）＋1,500ポイント（ラクマ特典）」はこの合計です。

## SPUの「楽天ラクマ」との違い

楽天市場の[SPU](https://event.rakuten.co.jp/campaign/point-up/everyday/point/)にも「楽天ラクマ」の項目がありますが、別の特典です。

|      | 買いまわりラクマ特典            | SPUの楽天ラクマ                                       |
| ---- | ------------------------------- | ----------------------------------------------------- |
| 条件 | ラクマで合計1,000円以上**買う** | ラクマで月に合計2,000円以上**売って**発送通知を終える |
| 倍率 | +1倍                            | +0.5倍                                                |
| 期間 | 大型イベントの期間だけ          | 毎月                                                  |
| 上限 | 1回の開催で500ポイント          | 月に500ポイント                                       |

両方の条件を満たせば、どちらも付きます。

## これまでの開催と変わったこと

楽天ラクマの公式ページは開催のたびに同じURLで書き換わります。インターネットアーカイブに保存された過去のページと、2023年3月の楽天スーパーSALEの回の[公式ページ](https://rakuma.rakuten.co.jp/info/campaign/ichibasupersale/20230304_3059/)から、29回の開催の条件を読み取りました。

- 2023年\
  3月 楽天スーパーSALE、10月 お買い物マラソン、12月 楽天スーパーSALE
- 2024年\
  お買い物マラソン 2月・4月（2回）・5月・6月・7月・8月・9月・10月、楽天スーパーSALE 6月・9月
- 2025年\
  お買い物マラソン 2月・4月・5月（2回）・8月・9月・10月、楽天スーパーSALE 3月・6月・9月、ブラックフライデー 11月
- 2026年\
  お買い物マラソン 1月・4月・8月、ブラックフライデー 11月

読み取れた回はどれもお買い物マラソン、楽天スーパーSALE、ブラックフライデーのどれかと同じ期間でした。ページが保存されていない月に開かれたかはわからないので、すべての回で開かれたとは言えません。公式ページにも「毎回開催」とは書かれていません。

この間に変わったのは、次の3点です。

- 2025年6月の楽天スーパーSALEから、+1倍の上限が1,000ポイントから500ポイントになりました。ラクマでの買い物に付く特典3の上限は1,000ポイントのままで、2つを合わせた上限は2,000ポイントから1,500ポイントになりました。それ以降の回はすべて500ポイントです。
- 2023年3月の回では、このキャンペーンと楽天スーパーSALEの両方にエントリーが必要でした。2023年10月の回からはどちらかのページでエントリーすれば対象です。
- 2023年3月の回は、特典の番号が今と違いました。+1倍が「特典3」で、期間中にラクマで初めて買った人には500ポイントも付きました。2023年10月の回からは今と同じ3つの特典です。

## ポイントスプリントで計算する

お買い物マラソン、楽天スーパーSALE、ブラックフライデーのイベントから作った[ポイントスプリント](/)のプランには、「ラクマ購入 +1倍」が最初から入っています。ラクマで期間中に合計1,000円以上買ったら、プランの設定の「キャンペーン」で ON にします。

ON にすると、期間中に1,000円（税込）以上買ったショップの注文に+1倍を足し、上限の500ポイントまで数えます。1,000円に届かないショップの注文には付きません。
