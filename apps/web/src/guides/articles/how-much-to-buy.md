お買い物マラソンでは、買ったショップの数でポイントの倍率が上がり、もらえる特典のポイントには上限があります。この記事では、上限に届く金額の計算のしかたと店舗数ごとの金額、上限を超えたときの扱いをまとめ、買い物の前提を変えた3つの計算例で確かめます。

## 結論

- **上限の7,000ポイントは、買いまわりの特典の分だけにかかります。** 通常ポイントの1倍やSPUの分は、上限に届いた後も増えます。
- **上限に届くのは、10店舗で税抜77,778円の買い物。** 10%の商品なら税込でおよそ85,600円です。店舗が少ないと、上限に届く金額は大きくなります。5店舗なら税抜175,000円です。
- **店舗数は10店舗まで。** 確かめた時点の条件では、倍率は10店舗で最大になり、11店舗目からは増えません。
- **それより少ない買い物なら、上限は気にしなくてよい。** 上限に届かない人は、店舗数を増やすほどポイントが増えます。
- **上限は開催の回ごとに違います。** 5,000ポイントや10,000ポイントの回もあり、そのときは届く金額も変わります。

## 確かめた時点の買いまわりの条件

:::info
2026年10月19日と11月26日に、楽天の公式の案内（[お買い物マラソンのガイド](https://event.rakuten.co.jp/campaign/point-up/marathon/guide/)と[ルールがわかるクイズ](https://event.rakuten.co.jp/campaign/point-up/marathon/guide/quiz/)）で確かめた内容です。倍率と上限は開催回で変わるので、買う前にその回のエントリーページで確かめてください。開催中・開催予定の回の上限は、[お買い物マラソンの日程と上限](/marathon)にまとめています。
:::

- 参加にはエントリーが要ります。期間中にエントリーすれば、エントリーより前の購入も対象になります。
- 1ショップで税込1,000円以上買うと、1店舗と数えます。金額はクーポンを使った後で、送料やラッピングの料金を除いて判定します。同じショップで何回買っても1店舗で、金額は合計します。
- 倍率は店舗数と同じ倍数で、2店舗で2倍、10店舗で10倍です。10倍は、通常ポイントの1倍と買いまわりの特典の9倍を合わせた数字です。
- 11店舗以上買っても10倍のままです。ただし、2025年4月の第三弾のように、11店舗で11倍になった回もあります。
- 特典のポイントには上限があります。公式の案内では基本が7,000ポイント（期間限定ポイント）で、5,000ポイントや10,000ポイントの回もあります。特典のポイントは税抜の金額にかかります。
- 特典のポイントは、キャンペーンが終わった翌月の15日ごろに付きます。

## 上限がかかるのは特典のポイントだけ

上限の7,000ポイントは、買いまわりの特典の分だけにかかります。通常ポイントの1倍や、SPU（楽天カードや楽天モバイルなどで上がる倍率）のポイントは含まれません。公式のガイドにも、ショップ買いまわり以外のポイントアップキャンペーンは別に計算すると書かれています。

たとえば10店舗で税抜100,000円買うと、次のようになります。

| 内訳             | 倍率 |    ポイント |
| ---------------- | ---: | ----------: |
| 通常ポイント     |  1倍 |       1,000 |
| 買いまわりの特典 |  9倍 | 9,000→7,000 |
| 合計             |      |       8,000 |

特典は計算上9,000ポイントですが、上限の7,000ポイントで止まります。通常ポイントの1,000は上限と関係なく付くので、合計は8,000ポイントです。SPU があれば、その分も上限とは別に足されます。SPU にはそれぞれ月ごとの上限があります。

## 上限に届く金額

上限に届く金額は、上限のポイント数を特典の倍率で割ると出ます。

**上限に届く金額（税抜） ＝ 上限のポイント数 ÷ 特典の倍率**

10店舗なら特典は9倍（9%）なので、7,000 ÷ 0.09 ＝ 77,777.7…円です。ポイントは1ポイント未満を切り捨てるので、7,000ポイントに届くのは税抜77,778円からです。

上限が7,000ポイントのときの店舗数ごとの金額は次のとおりです。税込は10%の商品で買ったときの目安で、食品など8%の商品なら10店舗で税込84,000円です。

| 店舗数 | 特典 |      税抜 |        税込 |
| -----: | ---: | --------: | ----------: |
| 10店舗 |  9倍 |  77,778円 |  約85,600円 |
|  9店舗 |  8倍 |  87,500円 |  約96,300円 |
|  8店舗 |  7倍 | 100,000円 | 約110,000円 |
|  7店舗 |  6倍 | 116,667円 | 約128,300円 |
|  6店舗 |  5倍 | 140,000円 | 約154,000円 |
|  5店舗 |  4倍 | 175,000円 | 約192,500円 |
|  4店舗 |  3倍 | 233,334円 | 約256,700円 |
|  3店舗 |  2倍 | 350,000円 | 約385,000円 |
|  2店舗 |  1倍 | 700,000円 | 約770,000円 |

店舗が少ないと倍率が低いぶん、上限に届くまでに多く買う必要があります。期間中の買い物がこの金額より少ないなら、上限より店舗数を気にした方がポイントは増えます。

金額は1つの商品で買ったときの計算です。ポイントは商品ごとに切り捨てるので、商品が多いと、届く金額がこれより少し大きくなることがあります。

## 上限が違う回の計算

上限と倍率は開催の回ごとに決まり、回ごとに別にかかります。公式の案内に載っている回では、2025年4月の第一弾が5,000ポイント、2025年10月の第一弾と2026年2月の回が10,000ポイントでした。2026年11月19日から25日の楽天市場のブラックフライデーでも、ショップ買いまわりの上限は7,000ポイントでした。

上限が違う回でも、上限のポイント数を特典で割る計算は同じです。10店舗で特典9倍の回なら、次の金額で届きます。

| 上限           |      税抜 |        税込 |
| -------------- | --------: | ----------: |
| 5,000ポイント  |  55,556円 |  約61,100円 |
| 7,000ポイント  |  77,778円 |  約85,600円 |
| 10,000ポイント | 111,112円 | 約122,200円 |

2025年4月の第三弾のように、11店舗で特典10倍になる回では、上限7,000ポイントに税抜70,000円で届きます。

## 上限を超えた注文と店舗の扱い

上限に届いた後の買い物は、次のように扱われます。

- **特典のポイントは、上限を超えた分には付きません。** 通常ポイントやSPU、ほかのキャンペーンのポイントは付きます。
- **店舗数の数え方は変わりません。** 公式の案内の店舗数の条件は、1ショップで税込1,000円以上買うことで、上限に届いたかは条件に入っていません。ただし、上限に届いた後で店舗を増やして倍率が上がっても、特典のポイントは増えません。
- **それまでのポイントは減りません。** 上限に届いても、倍率が下がったり、それまでの特典が減ったりすることはありません。
- **キャンセルすると、店舗数と倍率が下がることがあります。** キャンセルした買い物は数えられないので、1,000円以上の買い物がほかにないショップは店舗数から外れ、残りの買い物すべての倍率が下がります。上限にちょうど届くように買ったときは、キャンセルで上限を割ることがあります。くわしくは[買う順番でポイントは変わるか](/guides/buying-order)にまとめています。

上限を超えたときに、特典のポイントをどの注文の分として付けるかは、公式の案内には書かれていません。ポイントスプリントは、日付の早い注文から順に上限を割り当てて、注文ごとのポイントを表示します。どう割り当てても、合計は同じです。

## 計算の前提

3つの例は、どれも次の前提で[ポイントスプリント](/)の計算と同じ方法で出しました。実際に付くポイントとは誤差が出ることがあります。

- 上限は7,000ポイント、10店舗で特典9倍の回とします
- 商品の税率は10%、クーポンと送料はありません
- ポイントは商品ごとに、税抜の金額に倍率をかけて、1ポイント未満を切り捨てます
- 例1と例2は、通常ポイントと買いまわりの特典だけを数えます

## 例1: 3,000円ずつ10店舗で買う

日用品などを1店舗3,000円ずつ買う場合です。この買い方では10店舗を回っても上限には遠く届きません。

| 店舗数 |     合計 | ポイント | 通常 | 買いまわり |
| -----: | -------: | -------: | ---: | ---------: |
|  9店舗 | 27,000円 |    2,205 |  243 |      1,962 |
| 10店舗 | 30,000円 |    2,720 |  270 |      2,450 |
| 11店舗 | 33,000円 |    2,992 |  297 |      2,695 |

10店舗目の3,000円で、ポイントは515増えます。倍率が上がると、それまでに買った9店舗の分にも新しい倍率がかかるからです。

11店舗目の3,000円では272ポイント増えます。倍率は上がりませんが、11店舗目の買い物にも10店舗と同じ倍率がかかります。上限まではまだ税抜で47,770円分あります。

## 例2: 8万円の家電を含めて買う

80,000円の家電を1つと、ほかに2,200円ずつ9店舗で買う場合です。合計は99,800円で、上限を超えます。

- 10店舗（合計99,800円）: 7,907ポイント。買いまわりは計算上8,165ポイントですが上限の7,000ポイントで止まり、残りは通常ポイントの907です
- 11店舗目に3,000円を足す: 7,934ポイント。増えるのは通常ポイントの27だけです

10店舗まで入れたときのプランの画面です。「ポイントの内訳」のマラソンが7,000Pで止まり、「あと何店舗回る？」の10店舗の行は「上限」になっています。

![例2を10店舗まで入れたプランの画面。獲得予定は7,907Pで、内訳はマラソン7,000P、通常907P](/guides/how-much-to-buy/marathon-cap-reached.webp)

この例では、ほかの9店舗を1,000円ずつ（合計89,000円）にしても買いまわりは上限の7,000ポイントに届き、全体は7,808ポイントです。9店舗で1,200円ずつ多く買った分には、通常ポイントの99しか付きません。

上限を超えた分には特典のポイントが付かないので、高い買い物があるときは、ほかの店舗は1,000円ずつで足ります。

## 例3: 楽天カードと楽天モバイルを使う

楽天カードで払い、楽天モバイルを契約している人が、10,000円ずつ5店舗で買う場合です。SPU は楽天カード（通常分と特典分）と楽天モバイル（4倍、上限は月2,000ポイント）を入れました。

- 5店舗（合計50,000円）: 5,030ポイント。うち楽天モバイルの分が1,815ポイントです
- 1,000円ずつ5店舗を足して10店舗（合計55,000円）: 8,030ポイント

5,000円を足しただけで3,000ポイント増えます。カードもモバイルも使わない人なら、同じ買い物で2,265ポイントから4,990ポイントに増えます。どちらの人でも、店舗を増やすとポイントが大きく増えます。

違いが出るのは上限です。この人は買いまわりより先に楽天モバイルの上限に届きます。10店舗の時点で楽天モバイルの分は1,995ポイントと、月の上限の2,000ポイントにほぼ届いていて、これ以上買ってもほとんど増えません。買いまわりの上限までは、まだ税抜で27,773円分あります。

SPU の上限は月ごとなので、同じ月のほかの買い物も合わせて数えます。

10店舗まで入れたときの「上限までの残り」です。楽天モバイルは1,995 / 2,000Pで、税込137円の買い物で上限に届きます。ショップ買いまわりは4,495 / 7,000Pで、まだ届いていません。

![例3を10店舗まで入れたときの「上限までの残り」。楽天モバイルは1,995 / 2,000P、ショップ買いまわりは4,495 / 7,000P](/guides/how-much-to-buy/spu-cap-remaining.webp)

## 11店舗目で何が起きるか

例1と例2をまとめると、11店舗目の買い物で起きることは、上限に届いているかで分かれます。

- 上限に届いていないとき: 倍率は上がりませんが、11店舗目の買い物にも10店舗と同じ倍率がかかります
- 上限に届いているとき: 特典のポイントは増えず、通常ポイントやSPUの分だけが増えます

11店舗目で倍率が下がったり、それまでのポイントが減ったりすることはありません。ただし、11店舗で倍率が上がる回もあるので、その回の条件で確かめてください。

## 自分の買い物で確かめる

自分の買い物で上限に届くか、あと何店舗で倍率が上がるかは、ポイントスプリントの計算ツールで確かめられます。

:::timeline

1. イベントを選ぶ

   [トップページ](/)で、開催中・開催予定のお買い物マラソンを選び、「このイベントでプランを作る」を押します。

2. 買うものを入れる

   プランの画面で、買う予定の注文を店舗ごとに入れます。「SPU の設定」の「変更」から、楽天カードや楽天モバイルなど、達成している SPU を ON にします。SPU は月ごとに覚えるので、同じ月のほかのプランにも反映されます。

3. ポイントと残りがわかる

   「あと何店舗回る？」で、店舗数ごとの倍率と、上限まであといくら買えるかを見ます。「上限までの残り」では、SPU も含めて上限ごとにあといくらで届くかが分かります。
   :::

:::button
[自分の買い物で計算してみる](/)
:::

例3の5店舗の時点で、「あと何店舗回る？」の「ほかの店舗数を見る」を開くと、次のように並びます。右の列は、その店舗数まで回ったときに上限まであと税抜でいくら買えるかの目安です。10店舗まで回れば、あと約3.2万円で上限に届きます。
