実際に付与されるポイントとは誤差が出ることがあります。気になるときは、出典のページで確かめてください。

## 計算の流れ

ポイントは注文の商品ごとに次の順で計算します。10月5日（5と0のつく日）に、楽天市場のショップで税込 {{price}}（税率10%）の商品を1つ、楽天カードで買う例で追います。SPU は楽天カードだけを達成しているとします。

:::flow

| 段階           | 例               | 内容                                                                                                                            |
| -------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 対象額を決める | {{price}}        | クーポンを使った後の金額です。送料とラッピング料は含めません（[楽天市場 FAQ](https://ichiba.faq.rakuten.net/detail/000030997)） |
| 税抜にする     | {{tax-excluded}} | 税込額から消費税額を引きます                                                                                                    |
| 倍率をかける   | × 倍率           | 特典ごとにかけ、小数点以下を切り捨てます（[楽天市場 FAQ](https://ichiba.faq.rakuten.net/detail/000006644)）                     |
| 上限で止める   | 上限まで         | 上限は特典ごとに、月ごと、開催ごとなどの単位で数えます                                                                          |
| 足す           | {{total}}        | 特典ごとのポイントの合計が、獲得予定のポイントです                                                                              |

:::

### 税抜の額

:::meter 税込 {{price}}

| 内訳     | 金額             |
| -------- | ---------------- |
| 税抜の額 | {{tax-excluded}} |
| 消費税額 | {{tax}}          |

:::
消費税額は「税込額 × 税率 ÷ (1 + 税率)」の小数点以下を切り捨てた額です。この例では {{price}} × 10 ÷ 110 で {{tax}} です。（[楽天市場 FAQ: ポイント付与対象金額](https://ichiba.faq.rakuten.net/detail/000030997)）

### 楽天カードは2つに分けて計算する

カード本体の還元（通常分）は税込の決済額が対象で、上限はありません。SPU の特典分は税抜の額が対象で、月の上限があります。（[SPU](https://event.rakuten.co.jp/campaign/point-up/everyday/point/)）

### 上限は同じ月のプランで分け合う

同じアカウントで同じ月や同じ開催のプランどうしは、上限を分け合います。上限を超えたときは、それぞれのプランのポイントの比で上限を分けます。

## 使っている倍率と上限

### SPU

{{spu-table}}

SPU は楽天市場の外での利用で達成が決まるものが多いため、プロフィールとプランの設定で自分で ON にします。楽天ブックスと楽天Koboは、そこでの 3,000円以上の注文がプランにあると自動で ON になります。

### キャンペーン

{{campaign-list}}

キャンペーンはエントリーしたものを自分で ON にします。勝ったら倍では、両チームが勝った日の倍率を +2倍にします。ご愛顧感謝デーは会員ランクで倍率が変わるので、足すときにランクを選びます。

買いまわり（手動）、合計額で倍率（手動）、自由な倍率は、倍率と上限を自分で入れるキャンペーンです。楽天の値を写していないので、上には載せていません。

### お買い物マラソン

買いまわりのショップ数を数えるときは、ショップごとに期間中の税込の額（クーポンを使った後、送料を除く）を合計し、1,000円以上のショップを 1 店舗とします。同じショップで何回買っても 1 店舗です。

{{shop-count}}

楽天ブックスもショップに数えます。楽天ラクマは 1 店舗に数えますが、ラクマでの購入には倍率が付きません。（[お買い物マラソン ガイド](https://event.rakuten.co.jp/campaign/point-up/marathon/guide/)、[ラクマ 買いまわり特典](https://rakuma.rakuten.co.jp/info/campaign/buy/kaimawari/)）

倍率と上限は回ごとに変わります。楽天の[お買い物マラソンのページ](https://event.rakuten.co.jp/campaign/point-up/marathon/)から自動で集め、トップページのイベントに出しています。

## 計算に入れていないもの

:::cards

| 項目                             |     |                                                                                                                  |
| -------------------------------- | --- | ---------------------------------------------------------------------------------------------------------------- |
| 送料とラッピング料               |     | 入力しません。そのため、楽天カードの通常分（送料を含む税込の決済額にかかる分）は、送料の分だけ少なく計算されます |
| 支払方法、会員ランク、エントリー |     | 注文からは分かりません。SPU とキャンペーンを自分の状況に合わせて ON / OFF してください                           |
| キャンペーンの細かい条件         |     | 対象外の商品やショップなどは扱いません                                                                           |
| 回ごとの変更                     |     | キャンペーンの倍率・上限・条件は回によって変わります。楽天の公式ページで確かめてからご利用ください               |

:::
