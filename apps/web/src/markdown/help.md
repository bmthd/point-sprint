# 使い方・注意事項

## このサイトは？

楽天市場で開催される、お買い物マラソンなどの楽天ポイント還元率を計算するサイトです。

お得に商品を買いたいあなたのポイ活を応援します！

## 使い方はショップと金額を打ち込むだけ！

1. トップページで開催中・開催予定のイベントを選んで「このイベントでプランを作る」を押します。イベントのない普段の買い物は「イベントを選ばずにプランを作る」から始めます。
2. プランの画面で「注文を追加」を押し、ショップと金額を入れます。商品のURLを貼ると、ショップと商品名・金額を自動で入れます。
3. 獲得予定のポイント、還元率、買いまわりの店舗数、あといくら購入できるのかが可視化され、計画的なお買い物に役立ちます。

SPUや0と5のつく日などの定番キャンペーンにも対応。購入画面では分かりづらかった、実際のおトク額がわかります！

## プラン

プランは、お買い物マラソンの1回分のような買い物の計画です。注文はプランごとに保存され、プランの一覧から過去の回も見返せます。

公式イベントからプランを作ると、その回の期間・買いまわり・キャンペーンが入ります。開催回で違うときは「プランの設定（SPU・上限・キャンペーン）」で倍率や上限を上書きしたり、エントリーしたキャンペーンを ON にしたりできます。

## 注文（1ショップでの購入）

注文は、1つのショップで行う1回の購入です。ショップ、日付、商品を持ちます。0と5のつく日などの日付で決まるキャンペーンは、注文の日付で判定します。

同じショップでまとめて買う商品は、注文の詳細設定の「同じショップの商品を追加」で1つの注文に入れます。

買いまわりのショップ数は、ショップごとに期間中の税込の金額（クーポン適用後、送料を除く）を合計し、1,000円以上のショップを1店舗と数えます。同じショップで何回注文しても1店舗です。

## 保留

買うか迷っている注文は保留にできます。保留中の注文は合計にも買いまわりのショップ数にも入らず、含めた場合のポイントを取り消し線で参考に表示します。

プランの画面では「買い回りにカウント」をオフにすると保留になります。注文の編集では、詳細設定の「保留（計算から外す）」で切り替えます。

## SPU の初期値

達成している SPU は、[プロフィール](/profile)の「SPU の初期値」で ON にします。ここでの設定は、これから作るプランの初期値になります。

プランを作るときに初期値をプランへ写すので、プロフィールを変えても作成済みのプランの計算は変わりません。作成済みのプランで変えるときは、プランの設定で SPU を切り替えます。

## ブラウザを閉じてもデータが保持

入力途中で離脱しても、次回アクセス時に続きから入力できます。

入力した内容はこのブラウザの中にだけ保存され、当サイトのサーバーには送信されません。商品のURLを貼ったときだけ、商品情報を取得するために商品のコードを楽天の商品検索APIへ送ります。

ブラウザのデータを消すと、プランも消えます。別の端末やブラウザとは共有されません。

## サイト利用上の注意事項

実際に付与されるポイントには誤差が出る可能性があります。参考としてご利用ください。

送料は入力しないため、楽天カードの通常分（税込の決済額にかかる分）は送料の分だけ少なく計算されます。

キャンペーンの倍率・上限・条件は回によって変わります。楽天の公式ページで確かめてからご利用ください。
