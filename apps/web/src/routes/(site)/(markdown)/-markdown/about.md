# このサイトについて

ポイントスプリントは、じょうげんが個人で作っている、楽天市場のポイント計算ツールです。楽天グループとは関係ありません。ソースコードはすべて公開しています。

## 作っている人

:::profile

お買い物マラソンのたびに、買いまわりのショップ数と上限までの残りを電卓とメモで数えていました。毎回の計算が面倒で、金額を入れるだけで分かるツールを作りました。

## ソースコード

計算のしかたと、サーバーに何を送っているかは、誰でもコードで確かめられます。ライセンスは MIT です。

[bmthd/point-sprint（GitHub）](https://github.com/bmthd/point-sprint)

## 費用と収益

無料で使えます。Google AdSense の広告と、買い物ガイドの楽天アフィリエイトのリンクで運営費をまかなっています。

## 楽天との関係

楽天グループ株式会社とは関係のない、個人のサイトです。商品の情報は楽天ウェブサービスの API から取得しています。

## データの扱い

入力した内容は、お使いのブラウザの中に保存されます。ほかの端末と同期するときも、端末の中で暗号にしてから送るので、運営者も中身を読めません。詳しくは[プライバシーポリシー](/privacy)をご覧ください。
