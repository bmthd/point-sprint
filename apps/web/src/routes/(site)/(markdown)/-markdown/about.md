# このサイトについて

ポイントスプリントは、じょうげんが個人で作っている、楽天市場のポイント計算ツールです。楽天グループとは関係ありません。ソースコードはすべて公開しています。

## 作っている人

::profile

楽天のお買い物マラソンをほぼ毎月走っている私ですが、以前から楽天のポイント還元率に分かりにくさを感じていました。特に、税抜価格をもとに計算されるようになってからは、実際にどれくらいお得なのかが見えにくくなり、つい衝動買いをしやすいと感じていました。

以前はスプレッドシートで表を作って管理していましたが、毎月変わるポイントの仕組みに 2 次元の表で追いつくのは無理がありました。そこで、当時覚えたてのプログラミングでサイトを作ったのが始まりです。

2026 年には、AI エージェントの力を借りて、サイトを一から作り直しました。正しい計算式、変わっていくルールへの追従、家族のアカウントや複数の端末での同期など、私がほしい機能を詰め込んでいます。

趣味で作っているツールですが、お役に立てれば幸いです。

## 費用と収益

無料で使えます。Google AdSense の広告と、買い物ガイドの楽天アフィリエイトのリンクで運営費をまかなっています。

## 楽天との関係

楽天グループ株式会社とは関係のない、個人のサイトです。商品の情報は楽天ウェブサービスの API から取得しています。

## データの扱い

入力した内容は、お使いのブラウザの中に保存されます。ほかの端末と同期するときも、端末の中で暗号にしてから送るので、運営者も中身を読めません。詳しくは[プライバシーポリシー](/privacy)をご覧ください。
