# 使い方

楽天市場で開催される、お買い物マラソンなどの楽天ポイント還元率を計算するサイトです。お得に商品を買いたいあなたのポイ活を応援します！

## 使い方は金額を打ち込むだけ！

:::timeline

1. イベントを選ぶ

   トップページで開催中・開催予定のイベントを選んで「プランを作る」を押します。終わったイベントは「終了したイベント」から選べます。イベントのない普段の買い物は「イベントを選ばずにプランを作る」から始めます。

2. 買うものを入れる

   プランの画面で「注文を追加」を押し、金額を入れます。ショップは任意です。未入力の注文は、それぞれ別のショップとして計算します。同じショップでの別の注文は、同じショップを指定してください。商品のURLを貼ると、ショップと商品名・金額を自動で入れます。

3. ポイントと残りがわかる

   獲得予定のポイント、還元率、買いまわりの店舗数、あといくら購入できるのかが可視化され、計画的なお買い物に役立ちます。SPU の項目ごとの上限の残りや、次の注文で何ポイント増えるかもわかるので、ポイントのための買いすぎを防げます。
   :::

SPUや0と5のつく日などの定番キャンペーンにも対応。購入画面では分かりづらかった、実際のおトク額がわかります！

## プラン

**プランは、お買い物マラソンの1回分のような買い物の計画です。**

:::figure{name="plan"}

1. 注文はプランごとに保存され、プランの一覧から過去の回も見返せます。
   :::

:::figure{name="event"}

1. 公式イベントからプランを作ると、その回の期間・買いまわり・キャンペーンが入ります。
2. 終わったイベントは「終了したイベント」から選べます。
   :::

開催回で違うときは「プランの設定（SPU・上限・キャンペーン）」で倍率や上限を上書きしたり、エントリーしたキャンペーンを ON にしたりできます。

## 注文（1ショップでの購入）

**注文は、1つのショップで行う1回の購入です。** ショップ、日付、商品を持ちます。

:::figure{name="edit-order"}

1. 0と5のつく日などの日付で決まるキャンペーンは、注文の日付で判定します。
2. 同じショップでまとめて買う商品は、注文の詳細設定の「同じショップの商品を追加」で1つの注文に入れます。
   :::

買いまわりのショップ数は、ショップごとに期間中の税込の金額（クーポン適用後、送料を除く）を合計し、1,000円以上のショップを1店舗と数えます。同じショップで何回注文しても1店舗です。

## 上限

**SPU の各項目やキャンペーンには、もらえるポイントの上限があります。** このアプリは上限を特典ごとに数えます。SPU の項目の上限は「月間獲得上限」なので、月ごとに数えます。同じ月の SPU や同じ回のキャンペーンを使うプランがほかにもあるときは、ほかのプランで使った分も差し引いて残りを出します。プランの画面の「上限までの残り」には、上限のある特典ごとに、使った分と、あといくらの商品を1つ買えば上限に届くかが並びます。

:::figure{name="caps"}

1. ほかのプランと共有している上限です。灰色はほかのプランで使った分、赤はこのプランで使った分です。右の「あと¥」の金額の商品を1つ買うと、上限に届きます。
2. 上限に届いた特典は、下にまとめて並びます。
   :::

### 買う前に、増えるポイントを確かめる

:::figure{name="new-order"}

1. 注文を追加するときは、保存する前に、その注文で増えるポイントがわかります。上限を超えて減る分や、店舗数が増えて買いまわりの倍率が上がり、ほかの注文のポイントが増える分も含めます。
2. 上限のある特典ごとに、この注文で入る分と、上限を使い切る金額が出ます。
   :::

買い足す価値があるかを、買う前に確かめられます。

※ 数えるのは、このアプリに入れた注文だけです。ほかで使った分は、入れていなければ残りに入りません。

## 保留

**買うか迷っている注文は保留にできます。**

:::figure{name="held-order"}

1. 保留中の注文は合計にも買いまわりのショップ数にも入らず、含めた場合のポイントを取り消し線で参考に表示します。
2. プランの画面では「購入決定」をオフにすると保留になります。
   :::

注文の編集では、詳細設定の「保留（計算から外す）」で切り替えます。

## 月ごとの SPU

**SPU（スーパーポイントアッププログラム）は、楽天カードや楽天モバイルなど、楽天のサービスを使っているほど楽天市場の買い物のポイント倍率が上がる仕組みです。** 楽天はアカウントと月ごとに判定するので、このアプリでも SPU を月ごとに設定し、すべてのプランで共有します。

注文には、その注文の日付の月の SPU が付きます。月をまたぐプランでは、10月の注文には10月の SPU、11月の注文には11月の SPU が付きます。

:::figure{name="spu-card"}

1. プランの画面の「SPU の設定」で月ごとの倍率を確かめ、「変更」から設定します。
   :::

:::figure{name="spu-months"}

1. 共通設定からも、今月と来月の SPU を設定できます。まだ設定していない月は「未設定」と出て、前の月から引き継いだ倍率で計算します。
   :::

### 月の SPU を変えたとき

:::figure{name="spu-month-bottom"}

1. 月の SPU を変えると、その月の注文があるほかのプランの計算も変わります。変わるプランは、月の SPU の画面の下に並びます。
2. 「上限」の印は、このプランでその項目の上限に達したことを示します。
   :::

### まだ設定していない月

:::figure{name="spu-month-top"}

1. まだ設定していない月は、前の月から「契約・お支払いで決まる」項目（楽天カード、楽天モバイル、楽天銀行など）を引き継ぎます。
2. 「その月の利用で決まる」項目（ファミリーマートでの買い物や投資信託など）は OFF から始まるので、達成したら ON にします。
   :::

## ブラウザを閉じてもデータが保持

**入力途中で離脱しても、次回アクセス時に続きから入力できます。**

入力した内容はこのブラウザの中に保存されます。ブラウザのデータを消すと、プランも消えます。PC とスマホなど、ほかの端末でも同じデータを使いたいときは、次の「ほかの端末と同期」を使います。

サーバーへ送る情報は[プライバシーポリシー](/privacy)にまとめています。

## ほかの端末と同期

**共通設定の「ほかの端末と同期」から、パスキーでログインすると、PC とスマホで同じプランと注文を使えます。** 名前やメールアドレス、パスワードは使いません。

:::figure{name="sync"}

1. 最初の端末で「パスキーで同期を始める」を押し、パスキーを作ります。このとき出る復元用のコードは、パスワード管理アプリやメモに控えてください。
2. ほかの端末では「ほかの端末で始めた同期にログイン」を押し、同じパスキーでログインします。PC では、ブラウザが出す QR コードをスマホで読み取ってログインすることもできます。
3. パスキーでデータの鍵を開けられない端末では、最初の 1 回だけ復元用のコードを入れてもらいます。
   :::

2 台で同じ注文を直したときは、あとから直したほうが残ります。電波が悪いときも書き込めて、つながったときに送ります。

:::warning
データは端末の中で暗号にしてから送るので、運営者も中身を読めません。そのため、パスキーと復元用のコードの両方をなくすと、サーバーにあるデータは誰にも戻せません。
:::

同期は、共通設定の「同期をやめる」でいつでもやめられます。サーバーにあるデータを消し、端末の中のデータは残します。

## 計算の誤差

**実際に付与されるポイントには誤差が出る可能性があります。** 参考としてご利用ください。

- 送料は入力しないため、楽天カードの通常分（税込の決済額にかかる分）は送料の分だけ少なく計算されます。
- キャンペーンの倍率・上限・条件は回によって変わります。楽天の公式ページで確かめてからご利用ください。
