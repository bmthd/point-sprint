# なぜポイントスプリントか？

楽天市場のポイントを計算するツールは、ほかにもいくつかあります。このページでは、ポイントスプリントがほかのツールとどう違うのか、どんな人に向くのかをまとめます。ほかのツールについて書いたことは、2026年11月23日に、楽天のポイント計算ツールと計算記事の8件を実際に開いて調べた結果です。

## どんな人に向くか

ポイントスプリントは、注文を1件ずつ入れて、買う前にポイントを詰めたい人に向いています。

- 買いまわりの店舗数や上限を見ながら、どの注文を足すか、外すかを決めたい人
- お買い物マラソンの期間中に、何日かに分けて買う人。5と0のつく日などは、注文の日付で判定します
- 家族のアカウントでも買う人や、PC とスマホで同じ計画を使いたい人

合計金額と店舗数から、おおよそのポイントだけを知りたいときは、合計を入れるだけの計算機のほうが早く答えが出ます。

## ほかの計算ツールとの比較

2026年11月23日の調査で確かめられた範囲で比べています。「確認できなかった」は、ツールを開いて探しても見つからなかったか、動かして確かめられなかったものです。その機能がないと決まったわけではありません。調べたツールは、このページの最後に並べています。

| 項目                                    | ポイントスプリント                               | ほかの計算ツール                                                                         |
| --------------------------------------- | ------------------------------------------------ | ---------------------------------------------------------------------------------------- |
| 入力                                    | 注文ごと（ショップ・金額・注文日・商品）         | 合計金額と店舗数を入れる形が主流。ショップごとに入れられるのは楽天経済圏の住人、とくらし |
| SPU・買いまわり・5と0のつく日をまとめる | できる                                           | 住人、とくらし、楽天市場公式でできる。公式は注文ごとではなく、月の金額で計算する         |
| キャンペーンごとの上限                  | 特典ごとに数え、ほかのプランで使った分も差し引く | 住人、とくらしは特典ごと。買いまわりの上限だけを見るツールもある                         |
| あといくら買えるか                      | 店舗数ごとの表と、上限ごとの残り                 | 多くのツールにある（残りの金額の表示や早見表）                                           |

## ほかのツールで確認できなかったこと

2026年11月23日の調査で、ほかの8件では確認できなかった機能です。

- **複数のプランを保存して切り替えられます。** お買い物マラソンの回ごとにプランを作り、過去の回も見返せます。同じ月の SPU や同じ回のキャンペーンを使うプランがほかにもあるときは、ほかのプランで使った分を差し引いて、上限までの残りを出します。
- **注文の並べ替え、編集、削除ができます。** 買うか迷っている注文は「購入決定」をオフにして保留にすると、合計と店舗数から外れ、外すと何ポイント減るかが分かります。
- **ショップ独自の倍率を、注文ごとに入れられます。** 期間中の合計額で倍率が決まるキャンペーンや、倍率を自由に決めたキャンペーンも足せます。
- **結果を共有できます。** 「結果をシェア」から、X・Facebook・LINE に送ったり、文面とリンクをコピーしたりできます。
- **データを書き出せます。** 共通設定の「データを書き出す」で、プラン・ショップ台帳・SPU と、計算したポイントを JSON ファイルに保存できます。

## 計算のしかた

楽天の数え方に合わせて、注文ごとに計算します。

- 注文ごとに、ショップ・金額・注文日・商品を入れます。39ショップ、リピート購入、24時間限定などの条件も注文ごとに付けられます。
- 買いまわりの店舗数は、ショップごとに税込の金額を合計し、1,000円以上のショップを1店舗と数えます。同じショップで何回注文しても1店舗です。
- ポイントは特典ごとに、楽天の決まりに合わせて商品ごとか注文ごとに、金額に倍率をかけて端数を切り捨てます。
- 5と0のつく日などの日付で決まるキャンペーンは、ツールを開いた日ではなく、注文の日付で判定します。SPU は月ごとに設定し、注文の日付の月の SPU を付けます。
- プランの画面には、「あと1店舗で全商品+1倍（約+○P）」のような次の1店舗で増えるポイントと、「あと何店舗回る？」の店舗数ごとの倍率と上限までの残りが出ます。
- お買い物マラソンの日程と上限は、楽天の告知ページから1日4回集めています。終わったイベントや、イベントのない普段の買い物でもプランを作れます。

## 保存と同期

- 登録はいりません。入力した内容は、お使いのブラウザの中に保存されます。
- パスキーでログインすると、PC とスマホで同じプランを使えます。データは端末の中で暗号にしてから送るので、運営者も中身を読めません。
- 複数の楽天アカウントを使い分けられます。キャンペーンの上限と SPU を、アカウントごとに分けて計算します。
- 注文で入れたショップは、ショップ台帳にたまります。

## 計算で確かめた記事

[買い物ガイド](/guides)では、ポイントスプリントに実際に入れた計算例で、ルールを確かめて書いています。たとえば[お買い物マラソンは買う順番でポイントが変わる？](/guides/buying-order)では、同じ買い物を並べ替えて計算し、合計が変わらないことを確かめました。[お買い物マラソンの日程と上限](/marathon)には、更新した時刻を載せています。

## ほかのツールが優れているところ

ほかのツールには、ポイントスプリントにはない良さもあります。

- **楽天経済圏の住人:** 開いた日に合わせて、5と0のつく日やワンダフルデーなどを自動で ON・OFF し、買いまわりの開催中は上限まで ON にします。「マラソン・スパセ中」「通常日」「全部OFF」のボタンで切り替えられ、考えることが最も少ない作りです。
- **とくらし:** ショップごとに税率と対象かどうかを切り替えられ、最後の店舗数ごとに「上限まであといくら買えるか」の表を出します。SPU の項目と上限を、カードの種類まで分けて細かく載せています。
- **Daily Hack:** 5と0のつく日の月の上限に対して、今月すでにもらった分を入れて残りを計算できます。ポイントスプリントは、入れた注文の分だけを数えます。
- **g00dgadget:** 月の買い物の金額とスマホ代から、楽天モバイルに乗り換えると何円得か損かを出します。
- **ゼロリッチ:** 合計金額と店舗数の2つを入れるだけで、上限までの残りまで出ます。税込と税抜も切り替えられます。
- **4SPU:** 楽天市場の商品の URL を貼って、買う予定の商品を足す方式です。実質の割引率と還元率という独自の指標も出します。

## ポイントスプリントが向かない人

- 合計金額と店舗数から、おおよそのポイントをすぐ知りたい人。合計を入れるだけの計算機のほうが早く済みます。
- 楽天モバイルに乗り換えると得かどうかを、円で比べたい人。SPU の損得を円で出すツールが向いています。
- 今月すでにもらったポイントを入れて、上限の残りを出したい人。ポイントスプリントは、入れた注文の分だけを数えます。
