# 公式イベントのマスタの更新

公式イベント（お買い物マラソン、楽天スーパーSALE など）のマスタは `packages/domain/src/master/events.ts` にある。トップページの「開催中・開催予定のイベント」には、終了日が今日以降のイベントだけが出る。マスタはデプロイのときだけ変わるので、次のイベントは開催の前に足してデプロイする。

## 担当と時期

- 担当はリポジトリの運営者。
- 毎日 9:00 に、ワークフロー「Event master」（`.github/workflows/event-master.yml`）がマスタを調べる。7 日後まで続くイベントが 1 つもないと、Issue「公式イベントのマスタに次のイベントを足す」を立てる。同じ題の Issue が開いていれば、新しく立てない。
- Issue が立つ前でも、楽天が次の回を告知したら足してよい。お買い物マラソンは月に 2〜3 回あり、月ごとのスケジュールのページにその月の回がまとめて載る。2026-10-09 には、10 月の 3 回がすべて載っていた。スケジュールのページがいつ公開されるかは、まだ確かめていない。確かめたらここに書く。
- 開催回のページ（キャンペーンの詳細と、エントリーのボタンがあるページ）は、開催の 2 日ほど前に公開されるとみられる。10 月のスケジュールのページは、開催の 2 日前の 10:00 からそのページへのボタンを出していた。

## 出典にするページ

楽天の公式のページだけを使う。まとめサイトや個人のブログの「予想」は使わない。告知されていない回は足さない。

| ページ | URL | 分かること |
|---|---|---|
| お買い物マラソン | https://event.rakuten.co.jp/campaign/point-up/marathon/ | 開催中か開催直前の回の期間、倍率、獲得上限、ラクマ特典など。開催していないときは「終了しました」とだけ出る |
| お買い物マラソンのスケジュール | https://event.rakuten.co.jp/campaign/point-up/marathon/schedule/ | その月の各回の期間 |
| ショップ買いまわりのガイド | https://event.rakuten.co.jp/campaign/point-up/marathon/guide/ | 買いまわりの倍率のしくみ（10 ショップで最大 10 倍）。よくある質問の例には古い回の期間と上限が残っているので、上限には使わない |
| 楽天スーパーSALE | https://event.rakuten.co.jp/campaign/supersale/ | スーパーSALE の期間、倍率、獲得上限 |

## 確かめること

- **期間。** 開始と終了の日時を写す。マスタは日付しか持てないので、日付だけを `period` と、買いまわりの `dateRule` に入れ、時刻はコメントに原文で残す（時刻の扱いは #69）。
- **倍率。** ショップ数ごとの倍率を `tiers` に入れる。通常の 1 倍を除いた分を入れるので、10 ショップで 10 倍なら `rate: 9`。11 ショップ以上の扱いも確かめる。
- **獲得上限。** 買いまわりの上限を `cap` に入れる。回ごとに違うことがある（同じ月でも第一弾だけ違うなど）。
- **その他の特典。** ラクマ特典のように達成条件をマスタで表せない特典は入れず、入れない理由をコメントに書く。

開催回のページがまだなく、倍率や上限がそのページでしか確かめられないときは、分かる範囲の出典で入れ、そのことをコメントに書く。開催回のページが公開されたら確かめ直し、違えば直す。

## 書き方

既存のイベントに合わせる。

- イベントごとに、出典の URL と確認日をコメントに書く。値ごとに、ページの表記を「」で引く。
- `id` は `marathon-<開始日>` のように、開始日で回を区別する。`sharedKey` も同じ値にする。一度公開した `id` は変えない。保存されたプランが `officialEventId` で参照している。
- 特典の `id` は新しい UUID にする（`uuidgen | tr A-Z a-z`）。マスタ全体で重ならないことを `master.test.ts` が確かめる。
- 終わったイベントは消さない。そのイベントから作ったプランが、名前の表示などに使っている。

足したら `pnpm check:all` を通し、PR を出す。main にマージするとデプロイされる。Issue が立っていれば、PR に `Closes #番号` を書く。
